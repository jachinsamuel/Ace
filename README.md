# Ace — AI-Powered Git Copilot

Ace is an intelligent terminal tool that understands what you want to do with Git and does it for you.
Type what you mean in plain English — Ace figures out the right git commands, explains what it's doing, and executes safely.

## Installation

```bash
pip install -e .
```

## Usage

```bash
ace "undo my last commit but keep changes"
ace commit
ace review
```
