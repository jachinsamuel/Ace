# Security Policy

## Supported Versions

Only the latest release version of Ace is supported with security updates. We encourage all users to upgrade to the latest version immediately when new releases are published.

| Version | Supported          |
| ------- | ------------------ |
| >=0.2.6 | 🟢 Yes             |
| <0.2.6  | ❌ No              |

---

## Reporting a Vulnerability

We take the security of Ace seriously. If you find a security vulnerability, please do not report it publicly via GitHub issues. Instead, follow these steps to report it responsibly:

1. **Email the Maintainers**
   Send a detailed email describing the vulnerability to **jachinsamuel007@gmail.com**.
2. **Provide Details**
   In your report, please include:
   * A description of the vulnerability and its potential impact.
   * Step-by-step instructions to reproduce the issue (including proof-of-concept code, if applicable).
   * Details of the environment (OS version, Python version, Ace version) in which the vulnerability was found.
3. **Wait for Response**
   We will acknowledge receipt of your vulnerability report within 48 hours and work with you to analyze and patch the issue.
4. **Coordinated Disclosure**
   We ask that you give us reasonable time to release a security update before disclosing the vulnerability publicly.

Thank you for helping keep Ace secure!
