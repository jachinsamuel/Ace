# Support Guidelines

Thank you for using Ace! If you need help, have questions, or want to interact with the project community, here is how you can find support.

---

## 🔍 Search Existing Documentation and Issues

Before asking a question or opening a bug report, please check:
1. **[README.md](file:///d:/Projects/Ace/README.md)**: Contains installation steps, configurations, and a quick-start guide.
2. **[GitHub Issues](https://github.com/jachinsamuel/Ace/issues)**: Search both open and closed issues. Someone else might have run into the same problem and resolved it already.

---

## 💬 Where to Get Help

### 1. GitHub Discussions
For general questions, design ideas, and community chat, please use **GitHub Discussions**. This is the best place for:
* "How do I do X with Ace?" questions.
* Pitching new feature ideas.
* Showing off your dashboard configuration or workflow setups.

### 2. GitHub Issues
If you have confirmed a bug or have a concrete feature request, please open a **GitHub Issue**:
* **Bug Reports**: Explain the steps to reproduce the issue, what output you expected, and what actually happened. Please paste CLI log tracebacks or screenshots if possible.
* **Feature Requests**: Describe the problem you want solved and the proposed CLI subcommand or TUI feature.
